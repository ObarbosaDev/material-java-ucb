# Atividade 4 - Conexão com Banco de Dados em Java

Projeto acadêmico desenvolvido em Java utilizando Maven e JDBC para conexão com banco de dados MySQL.

## Tecnologias Utilizadas

- Java
- Maven
- MySQL
- JDBC

## Estrutura do Projeto

```bash
bdconexao/
├── src/
├── target/
└── pom.xml
```

## Funcionalidades

- Conexão com banco de dados MySQL
- Estruturação utilizando Maven
- Implementação orientada a objetos
- Utilização do driver JDBC

## Configuração do Banco de Dados

A conexão foi configurada utilizando:

```java
private static final String URL = "jdbc:mysql://localhost:3307/bdconexao";
private static final String USUARIO = "root";
private static final String SENHA = "";
```

## Objetivo

O projeto tem como objetivo praticar a conexão entre aplicações Java e bancos de dados relacionais utilizando JDBC e MySQL.
